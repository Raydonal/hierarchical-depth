# htheoryR: Hierarchical Entropies (H-Theory), Native R Implementation

Native R companion to "Hierarchical entropies" (de Moraes, Brum, Macedo
and Vasconcelos, Physica A 699 (2026) 131899): the generalized
statistical factor as a Meijer G-function, the entropy generator it
inverts to under maximum entropy, and the log-cumulant depth estimator
used for identifiability and for the mixed-Poisson network application.
