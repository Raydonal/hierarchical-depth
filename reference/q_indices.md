# The two Tsallis indices for the `s=1`, `N=1` case (Eq. 65) – distinct and must not be conflated: `q` is the *entropy* index, `q_stat` the *distribution* index.

The two Tsallis indices for the `s=1`, `N=1` case (Eq. 65) – distinct
and must not be conflated: `q` is the *entropy* index, `q_stat` the
*distribution* index.

## Usage

``` r
q_indices(a)
```

## Arguments

  - a:
    
    Numeric vector of per-level shape parameters `(a_1, ..., a_N)`;
    length is the cascade depth `N` (empty for `N = 0`).

See details.
